## 启动方式

```bash
# 1. 启动服务端
cd server
npm install        # 首次运行
npm run dev        # 开发模式（tsx watch 热重载）
# 或双击 start_server.bat

# 2. 启动客户端
godot4 --path .
# 或在 Godot 编辑器中运行

# 流程：
# TitleScreen → 开始游戏 → LoginScreen → 自动生成设备ID → 登录 → 进入游戏
```
