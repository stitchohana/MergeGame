# 修仙系统实现方案

## 布局
GameScreen 顶部（TopBar 下方，y=101..404，302px × 780w）放置角色形象。点击角色打开详情弹窗。

```
y=0    ┌──────────────────────────┐
	   │ TopBar                    │ y=101
	   ├──────────────────────────┤
	   │                          │
	   │    ╔══════════════╗      │
	   │    ║  角色形象区域  ║      │ ← CultivationPanel
	   │    ║  (点击打开)   ║      │    y=101..404
	   │    ╚══════════════╝      │    显示角色形象+境界名
	   │                          │
	   ├──────────────────────────┤
	   │ GridView                 │ y=404
	   │ ...                      │
```

## 核心规则

### 修炼机制
- 每秒自动获得 3 点经验
- 经验累积到阈值 → 层数 +1，恢复少量灵力
- **跨境界突破需要特殊丹药**（如练气→筑基需筑基丹），不能自动突破
- 同境界内升级自动发生，不需要丹药

### 元进度
- 修炼进度不随游戏重启重置

### 丹药类型

丹药分为两类，通过 `pill_type` 字段区分：

| 类型 | pill_type | 用途 | 使用方式 |
|------|-----------|------|---------|
| 突破材料 | "breakthrough" | 跨境界突破时按配置列表消耗 | `CultivationService.try_breakthrough()` |
| 修炼丹 | "cultivation" | 增加修炼经验 | `CultivationService.add_exp(amount)` |

## 新文件清单

| 文件 | 说明 |
|------|------|
| `config/cultivation.json` | 境界配置：9 个境界，经验公式，突破丹药 ID |
| `autoload/CultivationService.gd` | 核心 autoload：Timer 每秒加经验，突破逻辑，信号 |
| `scenes/ui/CultivationPanel.tscn` + `.gd` | 主界面角色面板（顶部 302px） |
| `scenes/ui/CultivationDetail.tscn` + `.gd` | 详情弹窗（BasePopup，UIManager 管理） |

## 修改文件清单

| 文件 | 改动 |
|------|------|
| `config/items.json` | 新增 灵草、丹药、药田、炼丹炉、配方 |
| `config/cultivation.json` | 新增（境界配置） |
| `autoload/ConfigDatabase.gd` | 加载 cultivation.json，加查询函数 |
| `project.godot` | 注册 CultivationService autoload |
| `scenes/screens/GameScreen.tscn` | 插入 CultivationPanel 实例 |
| `scenes/screens/GameScreen.gd` | 连接 cultivation_clicked → 打开详情弹窗 |

## 实现顺序

1. `config/items.json` — 新增修仙物品（灵草、丹药、药田、炼丹炉、配方）
2. `config/cultivation.json` — 境界配置
3. `ConfigDatabase.gd` — 加载配置，加查询函数
4. `CultivationService.gd` — 核心逻辑、Timer、信号、存档序列化
5. `project.godot` — 注册 autoload
6. `CultivationPanel.tscn` + `.gd` — 主界面角色形象
7. `CultivationDetail.tscn` + `.gd` — 详情弹窗
8. `GameScreen.tscn` + `.gd` — 插入面板 + 连接信号
