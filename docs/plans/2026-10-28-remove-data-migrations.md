# 移除数据迁移实施计划

**Goal:** 客户端、服务端、配置工具仅使用当前结构，不再升级旧存档或旧配置；后续不新增迁移。

**Architecture:** 删除读取时的历史数据补齐、转换及奖励修复；保留新玩家/首次解锁初始化、周期重置、计时恢复和正常结算。数据库仅保留当前版本的schema.sql供新库建表，不执行任何现有数据库操作。

**Tech Stack:** Godot GDScript、TypeScript、Python、SQLite/D1。

1. 清理server/src/routes/game.ts登录迁移，删除game_engine.ts经验/订单修复、存量图鉴/设施解锁回填和储物袋容量修复；GM直接记录本次发放。
2. 清理card_collection.ts旧卡包计数及转换、quest_engine.ts历史领奖重置、secret_realm.ts布局升级和shop.ts旧商品过滤；完整初始化新进度。
3. 删除客户端与配置工具的旧结构转换，保留当前协议的必要显示与正常状态变化。更新数据类型和旧格式测试。
4. 将server/migrations三份建表合并为server/schema.sql，同步测试与部署说明；项目约定明确禁止迁移。
5. 验证当前存档首次/重复登录、卡包、任务、储物袋、秘境与订单；验证schema新库初始化和配置检查，运行Godot无界面回归与Worker编译。仅修改源码与测试，保留其他已有工作。

不自动提交、推送、部署，不删除玩家存档，不连接或改动数据库。现有旧结构存档不再保证兼容。

## 验证结果

- 服务端 51 项回归通过，包含当前存档重复登录不回填、经验与订单不重写、任务领奖标记保留、秘境不扩图、SQLite 新库建表及损坏 JSON 拒绝读取。
- Node 服务端与 Worker 构建通过；重新生成 `server/dist`，运行构建产物创建新玩家通过。
- Python 配置脚本语法和完整导表通过；清理前后导出 JSON 完全一致。已有 `activities.xlsx` 与当前 `activities.json` 的差异不属于本次修改，未覆盖项目配置。
- Godot 16 项客户端回归中 15 项正常通过；多倍体力测试全部断言通过并输出成功标记，但 Godot 4.7.1 退出阶段出现异常/超时，进程退出未验证通过。编辑器导入未发现脚本解析错误；环境另有系统证书读取及编辑器设置写入错误。
- 当前源码与生成运行代码检索未发现迁移入口；旧历史计划均补充废止说明。真实玩家存档和数据库未被访问或修改。
