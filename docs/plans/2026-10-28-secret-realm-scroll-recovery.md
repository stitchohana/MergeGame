# 秘境滚动仅回收离屏格物品

用户要求：棋盘推进时，仅消失格子中的物品回到暂存区，留在棋盘中的物品保留。

服务端结算明确限定“旧视口内、新视口外”的格子：0–7 行推进至 4–11 行时仅处理 0–3 行；再次推进至 8–15 行时仅处理 4–7 行。回收已揭雾物品并保持 UID 与固定属性，隐藏内容不发放。重叠行及未来区域保留原实例；最终 Boss 通关不移动棋盘，也不进行离屏回收。

客户端此前保留整块旧棋盘作为退出动画层，与新棋盘的重叠区域重复显示。现只显示真正离屏的旧格子，保留区域由新棋盘持续向下移动，避免旧物品或旧 Boss 在重叠区域重影。暂存按服务端结果同步，不由动画再次结算。

验证：服务端实际击败三个 Boss，分别检查两次滚动和最终通关，逐 UID 校验仅离屏已揭雾物品入暂存、其余物品坐标与固定属性不变、无重复实例、请求重放不重复回收。Godot 检查滚动起点重叠物品屏幕位置一致、旧层仅显示离屏行、滚动后可移动及固定剑气均保留，并覆盖动画期间关闭。服务端 smoke、完整推进和 Godot UI smoke 通过，完整推进仍为 169 次补给、634 次合成、2501 次操作，合成奖励零损失。
