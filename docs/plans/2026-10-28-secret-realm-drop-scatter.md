# 秘境奖励就近散落

合成奖励以产物所在格为中心，击败小怪或 Boss 的奖励以怪物原格为中心，按格子中心的直线距离从近到远散落。怪物被移除后原格也可接收奖励。相同距离按行、列排序，保证预览、确认和重试结果一致。

仅使用当前视口内已揭雾且没有物品或怪物的格子；近处占满则继续向外找，不能覆盖障碍或投放到迷雾和离屏区域。合成完成四邻揭雾后再选格，飞剑和剑气的奖励顺序及固定属性沿用原规则。

统一修改服务端奖励投放函数，分别传入合成产物格、怪物原格。客户端继续显示服务端返回的格子位置。合成空间不足仍先提示，确认后丢弃溢出部分；战斗空间不足仍进暂存。Boss 先掉落再推进，仅离屏物品按现有规则回收。

验证：产物中心、近处与远处优先级、对角扩散、迷雾和占用格、棋盘边界、乱序存档一致性、小怪及推进/最终 Boss、满盘溢出、只读预览、取消与幂等重试，以及正式操作完整地图推进。

结果：空间专项和服务端基础测试通过；完整推进为 173 次补给、648 次合成、2550 次操作，零合成奖励损失。全项目严格 TypeScript 检查仍存在 `game_engine.ts`、路由、存储等未修改文件中的类型错误，秘境结算文件无诊断。
