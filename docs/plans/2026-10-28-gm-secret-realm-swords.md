# GM 添加秘境飞剑

GM 面板新增“添加秘境飞剑”，输入数量（1～1000 把）和飞剑等级（1～12 级）。执行后全部进入秘境暂存，固定属性为可移动，不占用棋盘空格。切换到其他命令时隐藏等级输入并恢复原数值范围。

沿用鉴权与 GM Key、用户操作队列、存档保存流程。命令为 `add_secret_realm_swords`，参数 `amount` 为数量，`level` 为等级。例如：`{"cmd":"add_secret_realm_swords","amount":3,"level":7,"gm_key":"<已配置的 GM Key>"}`，向现有 `/api/gm/exec` 发起已登录 POST 请求。

参数要求正整数，拒绝越界和字符串。秘境须已解锁；未初始化则使用当前配置初始化，不重置已有进度；通关后仍可供给以测试剩余物品合成。通过现有 UID 分配及奖励暂存函数发放，每次成功增加秘境版本和游戏版本，使旧预览失效。

服务端保存后返回秘境视图和存储版本，客户端同步至秘境缓存并通知界面刷新。沿用版本检查，旧回包不得覆盖新视图。现有 GM 命令调用保持兼容。

验证覆盖等级/数量边界、错误不修改存档、鉴权、自动初始化、持久化、UID 唯一、棋盘不变、版本失效、通关供给，以及 Godot 参数显示、真实请求组装和回包同步。

结果：GM 秘境飞剑服务端及 Godot UI 专项通过；原有暂存领取与棋盘一键合成服务端测试、GM 一键合成 UI、秘境 UI 回归通过，Worker 配置的构建检查通过。
