# 弹窗输入拦截设计

## 目标

所有继承 `BasePopup` 并通过 `UIManager.show_popup()` 打开的弹窗，在显示和关闭淡出期间都必须拦截鼠标输入，不能触发游戏层、HUD 或更低层弹窗中的控件。

## 方案

- `BasePopup` 在每次显示与隐藏时强制铺满父级，并将鼠标过滤设为 `MOUSE_FILTER_STOP`。
- 基类接收空白区域的鼠标事件并调用 `accept_event()`，弹窗内部按钮仍按正常控件层级优先响应。
- 禁止滚轮事件穿过弹窗根节点继续传递。
- `UIManager` 等待关闭动画完成后再从活动弹窗栈移除，淡出期间继续保持全局输入锁定。
- 对使用 `_input()` 的底层需求列表增加活动弹窗检查，避免绕过 Godot GUI 事件链。
- 清理显式设为 `MOUSE_FILTER_IGNORE` 的弹窗根节点配置。

## 验收

- 任意弹窗打开后，点击弹窗外区域不会触发棋盘、顶部栏、底部按钮或下层弹窗。
- 弹窗内按钮仍可点击。
- 关闭淡出完成前连续点击不会触发下层 UI。
- 多层弹窗关闭顶部一层后，下一层仍保持输入拦截。
