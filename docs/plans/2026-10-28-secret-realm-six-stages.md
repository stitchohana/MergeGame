# 秘境六关扩展 Implementation Plan

**Goal:** 现有怪物消耗提高两级，增加三关，Boss 依次消耗 7～12 级飞剑 1～6 把。

**Architecture:** 延用秘境配置表和统一结算。视口 6×8、每关推进 4 行，六关地图扩展为 28 行；不更换期次、不清空旧存档，读取时补充新增区域，前三关已通关者接入第四关。

**Tech Stack:** Godot 4 GDScript、TypeScript、JSON、Excel 配置及 Python 校验。

## 1. 更新配置与地图

修改 `config/json_output/secret_realm.json`、`config/xlsx/secret_realm.xlsx`。Boss 飞剑等级 7/8/9/10/11/12，数量 1/2/3/4/5/6；按后续约定，6 级剑气数量为 1/1/2/3/4/5，从第三关开始每关递增一份。现有小怪飞剑 2/3/4 → 4/5/6，剑气 1 → 3；新关小怪飞剑 7/8/9、剑气 3，各一份。奖励延用现有实体体力、灵石。

新增逻辑行 16～27，固定飞剑随行升至 9/10/11 级，再保持 11 级，避免满级固定物品无法合成揭雾。每关新增两只小怪、一个 Boss，并在新区域各放两份固定 5 级剑气。保留既有区域配置，新增区域全部带迷雾。

## 2. 衔接旧存档

修改 `server/src/engine/secret_realm.ts` 的初始化流程：同一期次只追加新地图坐标，不覆盖现有物品、迷雾或击败状态。旧三关通关存档解除通关标记，推进至第四关视口，按原规则回收离屏物品。仅真正变化时增加版本；重复读取无副作用，已六关通关不重开。

## 3. 验证成本、地图与迁移

更新 `tests/secret_realm_config_smoke.py` 校验六关、28 行、全部 Boss 成本及预置上限。服务端测试覆盖多把飞剑不足时不部分扣除、锁定/隐藏物品不计入、最终 Boss 实际消耗、旧存档升级及重复读取。将原有写死三关的测试改为完整六关。

## 4. 验证可达性与界面

更新 `server/tests/secret_realm_progression_smoke.ts` 按配置推进所有关卡，并按本次合成的实际掉落数预留空间，正式操作通关且合成奖励不丢失。运行配置往返、服务端基础、空间专项、迁移、GM 与 Godot UI 测试以及 Worker 构建检查。用 artifact-tool 同步并渲染检查 Excel，更新 `config/CONFIG.md` 中当前规则与验证结果。
