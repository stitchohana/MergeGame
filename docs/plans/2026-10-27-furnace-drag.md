# 万象炉拖入同级转化实施计划

**Goal:** 拖入一个普通材料后弹出同级已解锁其他材料列表，选择并确定后产物飞回投料格。

**Architecture:** 复用棋盘拖放、法宝请求/次数和聚宝盆飞行控制器。服务端材料池决定目标资格；单件同级一换一，不按价值补差。选择和预览不消耗，确定后服务端原子保存投料、产物、次数和防重回执。

**Tech Stack:** Godot Control/TextureRect、GDScript、TypeScript、JSON/XLSX。

1. 服务端限制单个投料、同级且不同的合法目标；产物使用投料腾出的空格。覆盖满盘、非法/未解锁/不同级目标、重复请求和保存失败。
2. 万象炉入口接收拖放；点击仍打开介绍和加次。复用同步屏障，选择期间隐藏投料；取消、失败或离开画面恢复显示。
3. 新增同级目标选择弹窗，沿用米白底、青玉边框，图标卡片可单选，选中后服务端预览，确定直接使用；无目标、无次数、等待请求时给出明确状态。
4. 复用双法宝的权威结果飞行动画，成功关闭弹窗，产物从万象炉飞到投料格，重复响应不重复创建动画。
5. 更新配置文案及工作簿、原设计说明；运行服务端 smoke、Godot 拖放/弹窗/动画 smoke、法宝回归、导表和 Worker 类型检查，并检查实际渲染。

本轮在已有未提交改动上局部开发，不提交或部署。
