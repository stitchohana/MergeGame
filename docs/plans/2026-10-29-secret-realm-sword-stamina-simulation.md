# 一级飞剑的订单体力成本模拟

按当前配置，每笔有效主棋盘订单发放 3 把一级飞剑至秘境暂存，飞剑平均分摊成本为订单生产体力 / 3。秘境解锁时自带的三把飞剑、GM 和秘境合成额外掉落不计入订单来源。

| 修为 | 平均每单生产体力 | 每把一级飞剑分摊体力 |
| --- | ---: | ---: |
| 练气一层（刚解锁） | 19.56 | 6.52 |
| 练气四层 | 26.80 | 8.93 |
| 练气九层 | 35.75 | 11.92 |
| 筑基前期 | 768.18 | 256.06 |

每个修为使用 3 个固定随机种子，各完成 10,000 单，共 30,000 单、90,000 把飞剑。复用当前 TypeScript 引擎的订单池、批次去重与排序、配方查询及加权产出选择；以秘境服务实际发放验证每单三把。只写本地模拟文件，不修改游戏配置和玩家存档。

生产设施来自初始配置及进入该修为前所有周天和突破奖励；同类设施尽可能合并，模拟期间不继续升级。材料从零开始，每次取目标链预期产出最高的已拥有生产器，按实际权重抽样，二合一消耗低阶材料，配方递归生产；配方仅选已有设施且材料确实可生产的配方。配方可直接生产时优先制作，否则通过低阶产物合成。完整完成每批所有订单，多余材料保留供后续订单。

这是生产成本模型，并非完整实玩模拟：使用 1 倍体力产出；忽略棋盘/暂存容量限制与生产器冷却；不计活动订单补给等免费材料、不计初始固定材料，也不扣奖励体力返还或自然恢复。多余副产物可以无限保留，设施和修为固定，因此不能解释为玩家实际净体力或通关体力。产出抽样复用权重逻辑，不复现某个玩家的确定性生产序列；策略并非最优策略。

筑基前期订单普通材料升为 7–8 级、配方产物升为 5–8 级，而飞剑仍每单三把，造成这个模型中的成本跃升。若以一级飞剑作为活动统一进度单位，按订单数发放会随主棋盘阶段产生明显成本差异。
