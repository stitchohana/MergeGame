# 周常任务积分与阶段奖励

任务达标后，首次领取任务奖励时获得积分；自动领奖任务随奖励到账计分。默认每任务 10 分，50/100/200/350 分分别领取 30 体力、2 星卡包、60 体力、3 星卡包。阶段奖励额外发放，不扣积分，每周每阶段只领一次。

配置在 weekly_tasks.xlsx 中维护：原 weekly_tasks 页增加 points_per_task，milestones 页维护 activity_id、stage、required_points 和奖励。双向导表校验正整数、重复任务、重复阶段和阈值可达性。

服务端 WeeklyTaskService 负责领奖计分、周期状态和阶段领奖；QuestEngine 在任务奖励成功发放并标记 claimed 时计分，奖励、积分与领取标记一起保存。任务达标但未领奖不计分，重复领奖不再加分。解锁活动时创建完整积分状态，首次解锁此功能从零开始；不回算历史完成、不添加存档迁移。北京时间周一 reset_hour 同时清除积分、已计分任务和已领阶段。

客户端从服务端同步定义和进度。周常面板在任务列表上方显示积分条和四个阶段奖励卡；奖励预览用现有图标组件，任务标注完成所得积分。请求等待时禁用领奖按钮，失败可重试，跨周状态冲突刷新。

实施顺序：配置及双向导表 → 服务端计分和原子领奖接口 → 客户端同步与界面 → 服务端完成/重复/存档失败/跨周测试、Godot UI 测试与截图、配置表回读核对。
