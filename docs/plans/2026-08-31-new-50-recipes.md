# New 50 Recipe Products Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add 50 new craftable products and 50 recipes that combine the five newly added material chains with existing materials.

**Architecture:** Treat the two XLSX workbooks as source data. Append recipe products and recipes, extend the corresponding crafting-table recipe lists, then regenerate JSON through the existing converter. Keep effect configuration and art assets out of scope.

**Tech Stack:** Excel/XLSX, `@oai/artifact-tool`, Python configuration exporter, JSON, Godot 4 configuration loading.

---

**Files:**
- Create: `docs/plans/2026-08-31-new-50-recipes-design.md`
- Test: generated catalog validation executed before workbook edits

1. Define IDs 211–260 and result IDs 28101–28150.
