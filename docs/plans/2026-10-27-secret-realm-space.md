# 秘境初始梯度与合成掉落空间

目标：固定飞剑随地图向上推进逐级提高；合成掉落放不下时必须告知损失并由玩家确认。

1. 配置：16 行按每两行一级，从下往上 1–8 级；三个可移动一级起步物品不变。同步 JSON 与 Excel，校验固定飞剑等级不倒退，回归真实配置通关。已初始化存档不重置。
2. 服务端：共用实际合成模拟提供只读预览接口，在消耗源物品、生成产物、揭开四邻迷雾后计算空位；按掉落配置顺序投放。只对合成掉落丢弃溢出，订单、战斗奖励及离屏回收继续暂存。未确认损失拒绝结算并保持存档不变；确认绑定原版本、原操作，纳入防重签名。
3. 客户端：复用 ConfirmPopup，所有合成先请求服务器预览，无溢出自动结算，有溢出列出物品名称数量，取消不请求结算。请求期间、弹窗期间阻断棋盘；状态变化、失败及关闭清理预览，不复用旧确认。
4. 验证：覆盖源格释放、暂存合成不释放源格、揭雾带来空格、部分/全部损失、取消/确认、防重/状态冲突、断线与真实 HTTP 拖拽；运行主棋盘及秘境回归，并核对 Excel/JSON 往返。
