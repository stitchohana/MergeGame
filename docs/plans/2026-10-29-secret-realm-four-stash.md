# 秘境暂存四格分类

将秘境暂存的单一队首入口改为四格：一级飞剑、二级飞剑、三级飞剑、其他物品。第四格包含四级及以上飞剑和所有剑气、体力、灵石等物品。每组保持原暂存顺序，各显示一件队首物品和组内剩余数量；空组保留淡化棋格，点击不投放。格子沿用主棋盘尺寸。

只改变客户端展示和选取入口，服务端仍使用原暂存数组、UID 和 place 请求。跨组连续点击复用既有飞行、格子预留及串行提交队列，已预留物品不再计入显示。回包重建时在四组中按 UID 恢复按下状态，避免另一组回包中断点击。移除已不存在的主动回收提示，满盘提示先合成或使用奖励腾格。

验证已通过：SecretRealmUISmoke、SecretRealmStashBurstSmoke、SecretRealmMergeDragSmoke；带 120 毫秒 HTTP 延迟的 SecretRealmStashBurstOnlineSmoke 从四组交错投放六件，校验版本递增、物品 UID/固定属性、独立空位、空组点击与满盘保护。模拟覆盖混合其他物品、按下到释放之间的回包、超时恢复、关闭清理。OpenGL 截图已检查四格及数量展示。没有修改存档结构、服务端结算或配置，没有部署。
