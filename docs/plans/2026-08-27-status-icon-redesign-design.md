# 设施状态角标设计

## 目标

取消制作台四种状态对物品整体颜色的控制，统一使用无文字、仙侠物件风格的右上角小型状态角标。发射器充能中仍使用右上角角标；可发射状态改为覆盖整个设施、中心透明的体力能量环，并播放呼吸动画。

## 图形语义

- 空闲：空心环与中性圆点，表示尚未开始处理。
- 已放入材料：多种材料叠层与加号，表示输入已准备。
- 处理中：环形进度箭头与火花，表示正在处理。
- 完成：金色徽记中的清晰对勾，表示处理已完成。
- 充能中：蓝青色进度环包围闪电，表示能量正在积累。
- 可操作：沿用 TopBar 体力闪电图标的青金轮廓，内部镂空，表示可以执行下一步。

## 状态规则

制作台四个图标互斥显示，状态变化不再修改 `modulate`。发射器充能时显示右上角充能图标；有剩余次数且未充能时隐藏右上角角标，显示缩小为当前 0.5 倍、填满设施区域的中心透明体力闪电轮廓，并循环执行呼吸动画：前 2 秒完全透明，随后放大淡入，峰值停留 1 秒，再缩小淡出，峰值缩放为 0.7、最大透明度为 0.7。图标采用透明 PNG，源尺寸 128×128。
