# 聚宝盆拖入与产物落盘

将棋盘单个普通低级材料拖到储物袋左侧的聚宝盆图标，松手即使用一次，不再经过材料勾选/使用确认。点击图标仍保留介绍与灵石加次；介绍中的使用按钮返回棋盘并提示拖入。

先同步已有棋盘操作，服务端预览后客户端自动提交同一报价。提交期间阻止其他操作，失败保留物品和次数，超时沿用原请求重试。锁定、无次数或无效物品明确提示，不自动购买。

服务端消耗一个实例后逐个放置两个同链境界最高级产物：优先投料腾出的格子及其最近空位，每个格子仅放一个，无空位的部分进入已有暂存区。满棋盘时消耗投料腾出一格，因此一件落盘、一件暂存。结算和 UID 分配与次数一起保存，原请求重试返回原产物去向。

客户端收到权威状态后，从聚宝盆图标飞出两个产物，落盘产物在飞行期间隐藏，落地再显示；暂存产物飞向暂存入口。动画不创建奖励，关闭画面不影响已保存结果。

验证空棋盘、仅一空位、满棋盘、重试、防重、保存回滚，以及拖放命中、失败恢复、动画落点和状态同步。

## 实施与验证结果

- 服务端按投料位置查找最近空格，两个独立 UID 产物与投料、次数、回执一并保存；重试返回原去向，保存失败不产生部分结果。
- `BasinController` 处理拖放、同步、预览提交、失败恢复和双产物飞行；棋盘重建时保留隐藏状态，重复响应不重复播放，中途退出清理动画与输入锁。
- 聚宝盆结算重建棋盘时跳过原缩放生成动画，避免飞行目标偏移。介绍文案、JSON、XLSX 和配置说明均已同步。
- `server/tests/golden_finger_smoke.ts`、`tests/BasinDragUISmoke.tscn`、`tests/GoldenFingerUISmoke.tscn`、配置完整导表往返、Worker TypeScript 检查和 `git diff --check` 均通过。
- 聚宝盆 UI 测试验证拖放区域命中、离线与次数不足恢复、同步取消、刷新保持隐藏、两个飞行节点及落点、满盘暂存、重复响应和退出清理。另已运行 OpenGL 390×844 实际渲染并检查截图：`.codex_tmp/basin_board_flight.png`、`.codex_tmp/basin_pending_flight.png`。
- Godot 有环境原有根证书读取提示；本次离线 UI 测试未连接服务端。未执行部署或真实玩家存档操作。
