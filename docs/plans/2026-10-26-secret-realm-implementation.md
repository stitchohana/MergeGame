# 秘境活动 Implementation Plan

**Goal:** 实现可从活动入口游玩的 6×8 秘境：订单补给、合成解锁与揭雾、小怪实物奖励、点击使用和 Boss 自动推进。

**Architecture:** 独立 SecretRealmService 与活动存档，不切换现有 MAIN/BATTLE 棋盘；所有写请求在玩家队列中基于副本校验、保存和防重。Godot Control 弹层独立渲染地图及迷雾，沿用 CloudService 请求队列与状态版本。

**Tech Stack:** TypeScript / Godot 4 GDScript / JSON / openpyxl。

**Status:** 已完成。客户端缓存由 CloudService 独立维护，不额外修改 ActivityManager；运行时仍使用项目现有 openpyxl 导表，交付工作簿使用 artifact-tool 创建并校验。

## 首版实现取值

- 活动 ID 9，常驻三关；6 列，8 行视口，每关推进 4 行。
- 初始三个可移动一级飞剑；其余格预置固定飞剑、小怪或 Boss。四类合成均揭示产物四邻迷雾。
- 仅已揭雾、可移动的当前棋盘物品与暂存物品可提交怪物需求；固定飞剑先合成解锁。隐藏离屏内容不回收，不要求全清迷雾/小怪。
- 暂存物品仅通过点击自动飞入已揭雾空格，禁止暂存拖拽；固定物品投放保留固定属性。可移动物品先投放再在棋盘拖拽合成，并可主动收回暂存。
- 体力/灵石各三级，合成后（2 级起）可点击使用；溢出掉落转暂存；体力使用沿用现有增加体力规则。
- 数值及地图内容在独立 Excel/JSON 维护；本次不部署、不提交混有用户改动的 Git 记录。
