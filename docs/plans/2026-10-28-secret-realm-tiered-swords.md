# 秘境累计飞剑掉落

后续规则已调整为最多掉落两把，具体见 `2026-10-28-secret-realm-two-sword-drops.md`；本文保留此前累计掉落实施记录。

合成产物达到不同等级时，除对应剑气外，掉落 1～n 级固定飞剑各一把。

| 合成产物等级 | 飞剑掉落 | 剑气掉落 |
| --- | --- | --- |
| 2–4 | 无 | 无 |
| 5–6 | 1级一把 | 1级一份 |
| 7–8 | 1–2级各一把 | 2级一份 |
| 9–10 | 1–3级各一把 | 3级一份 |
| 11–12 | 1–4级各一把 | 4级一份 |

飞剑掉落不可移动，剑气掉落可移动。先放剑气，再按飞剑等级由低到高投放。沿用现有配置驱动的合成结算，不新增分支算法。同步秘境 Excel 配置和导出的 JSON，不重置已有进度。

合成释放的源格和产物四邻揭雾后的空格可接收掉落。无空位的部分在预览中列明名称和数量，取消不消耗，确认后仅丢弃溢出部分，不转暂存；重试不得重复发奖。

验证覆盖全部产物等级、固定属性、满盘及部分溢出、取消原子性、确认重放、客户端损失提示、Excel/JSON 一致性与完整地图推进。

验证结果：配置、服务端基础、空间专项和 Godot UI 测试均通过；完整推进记录为 173 次补给、648 次合成、2542 次操作，合成奖励零丢失。此记录用于验证流程可达，不表示最优操作次数。
