# 秘境奖励点击使用

移除秘境面板的“使用奖励”和“收回暂存”按钮及手动回收入口。离屏回收和奖励溢出暂存保持现有结算。

棋盘上的体力、灵石第一次点击选中，第二次点击同一物品使用，与主棋盘一致，不要求快速双击。只有完整点击释放才使用，拖拽、按下后移出格子不使用；切换物品重新选中。保留二级起可用、固定物品不可用、服务端确认后结算的规则。暂存仍点击投放，投放至棋盘后才能使用。

在现有秘境 UI 回归中验证两种资源的实际指针点击、不可使用物品、拖拽与忙碌状态，以及两个按钮已移除；同时运行暂存连续投放与合并期间拖拽回归。

验证结果：`SecretRealmUISmoke`、`SecretRealmStashBurstSmoke`、`SecretRealmMergeDragSmoke` 均通过。
