# 秘境合成最多掉落两把飞剑

每次合成飞剑的额外飞剑掉落最多两把。延用原产物等级分档，保留该分档中最高的两级飞剑，各一把；只有一级的分档仍掉一把。

| 合成产物 | 固定飞剑掉落 | 可移动剑气掉落 |
| --- | --- | --- |
| 2–4级 | 无 | 无 |
| 5–6级 | 1级一把 | 1级一份 |
| 7–8级 | 1、2级各一把 | 2级一份 |
| 9–10级 | 2、3级各一把 | 3级一份 |
| 11–12级 | 3、4级各一把 | 4级一份 |

合成产物本身不计入两把上限。仍先放剑气，再按飞剑等级升序向产物附近空格发放；掉落飞剑仍不可移动。合成溢出预览、确认、重试规则沿用既有实现，怪物奖励和六关消耗沿用当前配置，不重置已有物品和进度。

同步 JSON 和 Excel `merge_drops`，导表校验及服务端配置加载均按实际数量检查每个产物等级匹配的全部规则，拒绝单条或叠加规则导致飞剑掉落超过两把。

验证覆盖 2～12 级实际合成数量、等级与固定属性、只读预览、部分溢出、取消与确认重试、就近散落、配置往返、错误配置及六关完整推进。

验证结果：配置往返及错误配置、服务端基础、空间与就近散落、扩关与旧存档、GM、Worker 编译及 Godot UI 测试均通过。六关完整推进以正式补给和操作通关，共 6359 次补给、23108 次合成、91588 次操作，合成奖励零丢失；该记录验证可达性，不代表最优操作数。Excel 与 JSON 一致，其余配置表数据未变。
