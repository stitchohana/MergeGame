# 秘境高阶飞剑掉落剑气分档

本文记录剑气分档实施阶段；飞剑掉落已由后续的 `2026-10-28-secret-realm-tiered-swords.md` 更新为 1～n 级各一把。

用户确认采用每两级飞剑提升一级剑气的分档，按合成后的产物等级判定：

| 飞剑产物等级 | 剑气掉落 |
| --- | --- |
| 2–4 | 无 |
| 5–6 | 一级剑气 ×1 |
| 7–8 | 二级剑气 ×1 |
| 9–10 | 三级剑气 ×1 |
| 11–12 | 四级剑气 ×1 |

所有掉落剑气可移动；5–12 级产物继续掉固定一级飞剑 ×1。四个剑气规则互斥，固定飞剑规则与对应剑气同时生效，先放剑气再放固定飞剑。预置固定剑气与现有存档保持原状，未来合成读取新掉落配置。

实现仅修改 `config/json_output/secret_realm.json` 与 `config/xlsx/secret_realm.xlsx` 的 `merge_drops`。服务端已有等级区间配置结算，客户端已有名称查询与空间损失提示，无须新增结算分支。

验证：Excel/JSON 往返与其余表值保持一致；实际合成覆盖 2–12 级，检查剑气等级、份数及可移动性；5–12 级逐级检查满盘只读预览、未确认不消耗、确认后不发放溢出奖励。Godot UI 检查四级剑气与一级飞剑的损失名称。服务端 smoke、空间专项、Godot UI smoke 与正式操作完整通关均通过。当前通关脚本仍采用低阶供给并合成剑气，记录 169 次补给、634 次合成、2501 次操作，零合成奖励损失；此记录不表示高阶飞剑策略的最少操作次数。未部署。
