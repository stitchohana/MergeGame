# 道具命名与描述设计

## 目标

为全部道具建立统一的古典修仙文风，同时降低跨品类重复。保留道具 ID、等级、类型、数值、配方、产出与效果字段，只调整 `name` 和 `describe`。

## 命名规则

- 名称控制在 2–6 个汉字，优先保证棋盘和弹窗中的可读性。
- 每条物品链使用独立词库：灵药重草木与药性意象，矿材重金石与地脉，灵泉重水脉与天象，兽材重形貌与血脉，建筑重结构与所在环境。
- 低阶使用山野、溪谷、陶木、砂石等朴素意象；中阶使用云霞、雷火、灵脉；高阶才使用洞天、太虚、先天、太初等意象。
- 不以“一阶、二阶”作为常规命名方式；效果类道具也改用可辨认的剑炁形态和丹药名称。
- 全局名称唯一，不允许不同品类共用同名道具。

## 描述规则

- 每条描述只写来历、产地、形态、气息、炼成过程或传说，不写用途、属性、数值和持续时间。
- 描述长度保持在约 18–48 个汉字，采用完整中文句子。
- 避免统一以“黄阶下品某某”开头；在同一品类内轮换叙述结构，例如“生于……”“传闻……”“每逢……”“以……炼成……”。
- 描述中的材料名优先引用本配置中的真实道具名，使世界观互相关联。

## 覆盖与验证

覆盖 `items_regular`、`items_recipe_product`、`items_effect`、`items_launcher`、`items_crafting` 五张表。完成后检查全局重名、描述重复、禁用功能词、名称与描述长度、Excel/JSON 一致性，并通过服务端配置加载验证。
